How does the encryption work?

1. Key derivation (PBKDF2): your master password is mixed with a random "salt" and hashed 600,000 times to make a 256-bit key. The slowness is on purpose: every guess an attacker makes costs them 600,000 hashes. The salt means two people with the same password still get different keys.

2. Encryption (AES-256-GCM): your logins are turned into JSON and encrypted with that key. A fresh random "IV" is used every time you save, so the same data never encrypts the same way twice.

3. Tamper detection: GCM adds an authentication tag. If anyone changes even one bit of the stored vault, or the password is wrong, decryption fails instead of returning garbage.

4. What's stored: only the salt, the IV and the encrypted data, in this browser's localStorage. Your master password and the key are never saved. They only exist in memory while the vault is unlocked.

This is a learning project. For your real passwords, use a well-tested manager like Bitwarden, 1Password or KeePassXC.
